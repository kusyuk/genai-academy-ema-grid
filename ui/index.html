Welcome to EMA Grid

Project Brief & Continuity

EMA Grid is an advanced, decision-intelligence expansion of our Cohort 1 prototype, EMA (Elderly Medical Assistant).

While EMA focus on assistant for elderly patients, EMA Grid focus on providing decision intelligence for healthcare professionals. Helping the hospital, medical officers and public health workers to make informed decisions based on real-time data gained from EMA. For this demo I include EMA and EMA Grid side by side to show the continuity and integration of the two.

Symmetrical 3-Panel Interface

The screen is divided into 3 responsive panels. You can drag the vertical resizers to adjust their sizes, or collapse panels using the minimal toggle buttons:

person

1. Patient Assistant

Simulates the patient app. Report symptoms via text, voice, or camera, and manage schedules.

analytics

2. Grid Console

Simulates the hospital official console. Inspect live outbreak hotspots, staffing alerts, and query data with the BQ Agent.

terminal

3. System Logs

Streams patient and grid agent logs side-by-side in real time. Can be collapsed to a slim vertical bar.
